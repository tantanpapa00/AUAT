자주 묻는 질문

전략 실행 ON 상태인 전략 1개 = 1슬롯입니다. OFF/일시정지된 전략은 슬롯을 차지하지 않습니다.
예시: 삼성전자 추세매매(ON) + BTC 역추세(ON) + ETH 역추세(OFF) = 2슬롯 사용
회원가입 후 자동으로 7일 무료체험이 시작됩니다. Pro 플랜의 모든 기능을 사용할 수 있으며, 체험 종료 후 원하는 플랜을 선택하시면 됩니다.
모든 API 키는 AES-256으로 암호화되어 저장됩니다. 출금 권한이 없는 거래 전용 API 키만 사용하시면 자산이 안전하게 보호됩니다.
결제 후 7일 이내 서비스를 이용하지 않았다면 전액 환불 가능합니다. 해지는 언제든 가능하며, 결제일까지 서비스를 이용하신 후 자동으로 종료됩니다.
