시작 가이드

BBooster를 처음 사용하시나요? 단계별로 안내해 드립니다.

1. 시작하기

BBooster는 TradingView 시그널을 받아 거래소/증권사에 자동으로 주문을 실행하는 자동매매 플랫폼입니다.

  • 회원가입 후 자동으로 7일 무료체험이 시작됩니다
  • PC 앱을 다운로드하여 설치합니다
  • 로그인하면 대시보드가 표시됩니다

2. 무료체험/결제

7일 무료체험

회원가입 즉시 Pro 플랜 7일 무료체험이 시작됩니다. 신용카드 등록 없이 모든 기능을 사용할 수 있습니다.

첫 결제 30% 할인

무료체험 종료 후 첫 번째 결제에 30% 할인이 자동 적용됩니다.

해지 방법

앱 설정 > 구독 관리에서 언제든 해지할 수 있습니다. 해지해도 결제일까지 서비스를 이용할 수 있습니다.

3. 활성 전략 슬롯

활성 전략 슬롯은 동시에 자동매매 ON 상태인 전략의 개수를 의미합니다.

💡 슬롯 계산 예시
삼성전자 추세매매(ON) + BTC 역추세(ON) + ETH 역추세(OFF) = 2슬롯 사용
OFF/일시정지된 전략은 슬롯을 차지하지 않습니다.

4. 자동매매 연결

Step 1: 거래소 선택

사용할 거래소/증권사를 선택합니다. OKX, 한국투자증권(국내/해외)을 지원합니다.

Step 2: 자산 선택

거래할 종목/코인을 검색하여 선택합니다.

Step 3: 리스크 설정

Sizing, Risk, Limits 탭에서 주문 크기와 리스크 관리 옵션을 설정합니다.

Step 4: 웹훅 URL 복사

생성된 웹훅 URL을 TradingView 얼럿에 붙여넣으면 연결 완료입니다.

5. 리스크 설정

Sizing (주문 크기)

  • 고정 수량: 매 주문마다 동일한 수량
  • 계좌 비율: 잔고의 N% 만큼 주문
  • 최대 금액: 주문당 최대 금액 제한

Limits (한도)

  • 일일 주문 횟수: 하루 최대 주문 횟수
  • 일일 손실 한도: 일일 최대 손실 금액
  • 최대 포지션: 동시 보유 가능한 최대 포지션

6. 문제 해결

주문이 안 나가요

  • API 키가 정상 등록되었는지 확인
  • 거래소 API 권한에 "거래" 권한이 포함되어 있는지 확인
  • 일일 주문 횟수 한도에 도달했는지 확인
  • 잔고가 충분한지 확인

API 키 오류

  • API 키, Secret, Passphrase(OKX)를 정확히 입력했는지 확인
  • IP 화이트리스트에 BBooster 서버 IP가 등록되어 있는지 확인

TradingView 얼럿이 작동 안 해요

  • 웹훅 URL이 정확히 복사되었는지 확인
  • TradingView 얼럿 설정에서 "Webhook URL" 옵션이 활성화되어 있는지 확인
