[중요 이슈/해결 로그]
- SQLAlchemy text()에서는 :param 바인딩을 사용해야 함. %(...) 방식은 오류.
- JSONB는 CAST(:values AS jsonb) / CAST(:defval AS jsonb) 방식으로 해결.
- PowerShell ConvertFrom-Json이 BOM/인코딩에서 깨져서 Python(utf-8-sig)로 clean json 생성으로 해결.
- 템플릿을 파일로 저장할 때 한글이 깨지는 건 저장 인코딩 문제이며, API 응답 자체는 정상.
