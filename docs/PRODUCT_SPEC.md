# 1-6) 제품 3종(사이트/PC/앱) 역할 분리 — SSOT 고정(중복개발 방지)

## A) 사이트(Web Site) — "비즈니스/계정/결제/법적고지/다운로드" 전용

**사이트에서 하는 것(고정):**
- 가입/로그인/계정관리
- 결제/구독 플랜/청구서/환불 정책 안내
- 제품 소개/가격/FAQ/공지
- 다운로드(PC 설치파일/릴리즈노트)
- 법적고지(면책/리스크/약관/개인정보/쿠키)
- (선택) 웹 대시보드(읽기 전용 중심): 계좌/자산/주문/상태 요약 보기

**사이트에서 "하지 않는 것"(고정):**
- API 키 등록/열람/변경 (보안상 PC/로컬 에이전트 영역)
- TradingView 템플릿 생성(초기에는 PC가 담당, 사이트는 문서/가이드만)
- 프리미엄 전략 파라미터 상세 설정(초기에는 PC/앱)

## B) PC 프로그램(Desktop App / 로컬 에이전트) — "설정/키/전략/템플릿/운영"의 본체

**PC에서 하는 것(고정):**
- 대시보드(실시간 상태/에러/주문/체결/캐시 상태)
- 계좌 등록 / API키 등록·변경 / 인증(2차인증 포함) / 키 암호화 저장
- 전략 설정(허브형/프리미엄형 모드 선택 포함)
- (허브형) TradingView 얼러트 메시지(템플릿) 생성/검증/테스트
- 시스템 설정(DRY_RUN/ORDER_SUBMIT_ENABLE/ORDER_POLL_ENABLE/E-STOP)
- 주문 내역/로그/내보내기(CSV 등)

**PC에서 "하지 않는 것"(초기 고정):**
- 마케팅/가격/결제 UI (사이트가 담당)
- 모바일 푸시의 최종 책임(앱/알림 서비스가 담당)

## C) 앱(Mobile App) — "관측 + 즉시중지 + 알림" 중심

**앱에서 하는 것(고정):**
- 대시보드(요약/상태/에러/체결 알림)
- E-STOP (즉시 ON/OFF)
- (프리미엄 사용자만) 프리미엄 파라미터 '간단 조정'(제한적으로)

**앱에서 "하지 않는 것"(고정):**
- TradingView 템플릿 생성/복잡 설정(모바일에서 환불/오주문 리스크 큼)
- API키 열람/복사/변경(원칙적으로 금지 또는 강한 2차인증 필요)

# 1-7) 허브형 vs 프리미엄형 경계(신호판단 포함 여부) — SSOT 고정

## 허브형(Hub Mode)
- TradingView가 신호를 만든다.
- Hub는 브릿지 + 사이징/가드 + 안정성 + 기록/관측 + 실행만 한다.
- /tv 입력은 "지원 필드만" 반영, 나머지는 무시/에러.
- 템플릿 생성/검증/에러코드(환불 방지)는 허브형의 핵심 제품 가치다.

## 프리미엄형(Premium Mode)
- "신호판단(엔진)"이 포함된다. (단, 종목추천/자동선정/스크리너는 금지)
- 프리미엄 엔진은 "사용자가 지정한 심볼/자산 범위 내에서만" 신호를 생성한다.
- 프리미엄 파라미터는 PC가 주 설정, 앱은 제한적 조정만 허용.
- 프리미엄 엔진은 주문 파이프라인(orders/status/poll)과 분리(플러그인 형태)한다.

# 1-8) 구독/권한/동기화(사이트 ↔ PC ↔ 앱) — 중복작업 방지 원칙

## 원칙
- 결제/구독 상태의 '정본'은 사이트(서버)다.
- PC/앱은 실행 시(또는 주기적으로) 서버에 토큰으로 조회하여 entitlement(권한)을 동기화한다.
- 권한 변경(업/다운그레이드/만료/환불) 시 PC/앱은 즉시 반영되어야 한다.

## 권한(예시)
- 허브형 사용 가능 여부
- 프리미엄 사용 가능 여부
- 심볼 개수 제한/로그 보관기간/기능 제한(템플릿 batch, export 등)

## 최소 기술 스펙(추정 작성 금지, 구현 시 증거로 확정)
- /api/auth/login → access_token
- /api/subscription/me → plan, expires_at, entitlements
- PC/앱은 토큰 만료/갱신 처리 필요

# 1-9) UI 범위(종합 UI) — "어디서 무엇을 보여줄지" 고정

## 공통(사이트/PC/앱이 공유하는 '보여주기' 데이터)
- 계좌 상태(health)
- 자산 상태(활성/비활성, 심볼, 마켓)
- 주문 상태(last_order_status, reason, last_checked_at)
- 체결 상태(filled_qty, avg_px)
- (선택) 타임라인 이벤트(진입/청산/체결 마커용)

## 표현 레벨
| 플랫폼 | 범위 |
|--------|------|
| 사이트 | 요약(읽기 전용) + 고객지원/문서/다운로드 |
| PC | 상세(설정/검증/템플릿/로그/내보내기) |
| 앱 | 요약 + 알림 + E-STOP + (프리미엄 한정) 간단 설정 |
