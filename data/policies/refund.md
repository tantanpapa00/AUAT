## 제1조 (환불 가능 조건)

**결제 후 7일 이내이며 서비스를 이용하지 않은 경우**에 한하여 전액 환불이 가능합니다.

여기서 "서비스 이용"이란 다음 중 어느 하나라도 해당하는 경우를 말합니다:
- 로그인
- 거래소 API 연동
- 전략 설정 또는 수정
- 자동매매 실행
- 시장 데이터 조회
- AI 리포트 생성
- 백테스트 실행

## 제2조 (환불 금액 산정)

### 1. 결제 후 7일 이내, 서비스 미이용
전액 환불

### 2. 결제 후 7일 이내, 서비스 이용
이용일수를 일할 공제한 금액을 환불합니다.

**산정 방식:**
```
환불금액 = 결제금액 - (결제금액 ÷ 30일 × 이용일수)
```

### 3. 결제 후 7일 경과
잔여 기간에 대한 일할 환불이 적용됩니다.

**산정 방식:**
```
환불금액 = 결제금액 ÷ 30일 × 잔여일수
```

**단, 잔여일수가 7일 미만인 경우 환불하지 않습니다.**

## 제3조 (프로모션 할인 적용 시)

프로모션 할인(첫 결제 30% 할인 등)을 적용받은 경우, 환불 시 **정상가 기준**으로 이용 금액을 산정하여 공제합니다.

**예시:**
- 정상가: 39,000원
- 할인가(30% 할인): 27,300원 결제
- 10일 이용 후 환불 요청
- 일일 정상 이용료: 39,000원 ÷ 30일 = 1,300원
- 10일 이용료: 1,300원 × 10일 = 13,000원
- 환불금액: 27,300원 - 13,000원 = 14,300원

## 제4조 (환불 처리 기간)

환불 처리는 결제 수단에 따라 **영업일 기준 3~7일**이 소요될 수 있습니다.

| 결제 수단 | 예상 처리 기간 |
|-----------|---------------|
| 신용카드 | 3~5 영업일 |
| 체크카드 | 3~5 영업일 |
| 계좌이체 | 3~7 영업일 |

## 제5조 (환불 불가 사유)

다음의 경우 환불이 불가능합니다:
- 결제 후 7일이 경과하고 잔여일수가 7일 미만인 경우
- 약관 위반으로 서비스 이용이 제한된 경우
- 허위 또는 부정한 방법으로 환불을 요청하는 경우

## 제6조 (환불 신청 방법)

환불은 다음 방법으로 신청할 수 있습니다:
- 서비스 내 설정 → 구독 관리 → 환불 신청
- 이메일: support@bbooster.io

환불 신청 시 다음 정보를 함께 제공해 주시기 바랍니다:
- 가입 이메일
- 결제일
- 환불 사유

## 제7조 (자동 갱신 해지)

유료 구독은 월 단위로 자동 갱신됩니다. 자동 갱신을 원하지 않는 경우 **갱신일 전일(24시간 전)까지** 해지해야 합니다.

해지 후에도 현재 구독 기간이 종료될 때까지 서비스를 이용할 수 있습니다.
