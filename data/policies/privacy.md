BBooster(이하 "서비스")는 「개인정보 보호법」에 따라 회원의 개인정보를 보호하고 이와 관련한 고충을 신속하고 원활하게 처리할 수 있도록 다음과 같이 개인정보 처리방침을 수립·공개합니다.

## 제1조 (수집하는 개인정보 항목)

**필수 수집 항목:**
- 소셜 로그인 시: 이메일 주소, 닉네임(표시명), 소셜 계정 고유 ID
- 이메일 가입 시: 이메일 주소, 비밀번호(bcrypt 암호화 저장)

**서비스 이용 과정에서 자동 수집:**
- 접속 로그(IP 주소, 접속 시간, 브라우저 정보), 서비스 이용 기록

**회원이 직접 입력하여 수집:**
- 거래소 API 키(서버 암호화 저장 + PC앱 OS Keyring 저장), 자동매매 전략 설정, 관심종목 목록

**선택 수집 항목:**
- 마케팅 수신 동의 여부

## 제2조 (개인정보의 수집·이용 목적)
- 회원 식별 및 가입 의사 확인
- 서비스 제공(자동매매, 시장분석, AI리포트 등)
- 거래소 API 연동 및 주문 실행
- 서비스 개선 및 신규 서비스 개발
- 고지사항 전달, 서비스 장애 안내, 자동갱신 결제 사전 고지
- 마케팅 정보 제공(동의한 경우에 한함)
- 부정 이용 방지 및 서비스 안전성 확보

## 제3조 (개인정보의 보유 및 이용 기간)
회원 탈퇴 시 지체 없이 파기합니다. 단, 관련 법령에 따라 보존이 필요한 경우:
- 계약 또는 청약철회 등에 관한 기록: 5년 (전자상거래법)
- 대금결제 및 재화 등의 공급에 관한 기록: 5년 (전자상거래법)
- 소비자 불만 또는 분쟁처리에 관한 기록: 3년 (전자상거래법)
- 접속에 관한 기록: 3개월 (통신비밀보호법)

보유 기간이 경과한 개인정보는 지체 없이 파기하며, 파기 방법은 전자적 파일은 복원 불가능한 방법으로 삭제, 종이 문서는 분쇄 또는 소각합니다.

## 제4조 (개인정보의 제3자 제공)
회사는 회원의 개인정보를 제3자에게 제공하지 않습니다. 단, 다음의 경우는 예외로 합니다:
- 회원이 사전에 동의한 경우
- 법령에 의거하여 수사기관 등에 제공이 요구되는 경우

## 제5조 (개인정보의 처리 위탁)
회사는 원활한 서비스 제공을 위해 다음과 같이 개인정보 처리를 위탁합니다:
- 토스페이먼츠: 결제 처리 (결제 정보)
- 서버 호스팅 업체: 서버 인프라 운영 (서비스 데이터)
- Anthropic (Claude AI): AI 리포트 생성 시 종목 재무 데이터 처리 (회원의 개인정보는 전송되지 않으며, 공개된 시장 데이터만 전송됩니다)

위탁업체가 변경되는 경우 지체 없이 본 방침을 통해 고지합니다.

## 제6조 (개인정보의 안전성 확보 조치)
회사는 다음과 같은 안전성 확보 조치를 취하고 있습니다:
- 비밀번호: bcrypt 단방향 암호화 저장
- 거래소 API 키: 서버에서 AES 등 대칭키 암호화 저장, PC앱에서는 OS Keyring(Windows Credential Manager / macOS Keychain) 활용
- 통신 암호화: HTTPS(TLS) 적용
- 인증: JWT 토큰 기반 (Access Token 24시간, Refresh Token 30일)
- 접근 권한 관리: 관리자/일반 회원 역할 구분
- 접속 기록 보관: IP 주소, 접속 시간 기록 보관

## 제7조 (회원의 권리·의무 및 행사 방법)
회원은 언제든지 자신의 개인정보를 조회, 수정, 삭제할 수 있습니다.

회원 탈퇴 요청 시 지체 없이 개인정보를 파기합니다(법령 보존 의무 기간 제외).

개인정보 열람, 정정, 삭제, 처리정지 요구는 서비스 내 설정 또는 이메일(support@bbooster.io)로 가능합니다.

회사는 요청 접수 후 10일 이내에 처리하며, 처리 지연 시 그 사유를 회원에게 통지합니다.

## 제8조 (쿠키의 사용)
서비스는 인증 토큰 저장 및 세션 관리를 위해 로컬 스토리지를 사용하며, 별도의 광고 추적 쿠키를 사용하지 않습니다.

## 제9조 (개인정보 보호책임자)
개인정보 보호에 관한 문의는 아래로 연락해 주시기 바랍니다.
이메일: support@bbooster.io

## 제10조 (권익침해 구제 방법)
개인정보 침해에 대한 신고나 상담이 필요한 경우 아래 기관에 문의할 수 있습니다:
- 개인정보침해신고센터 (privacy.kisa.or.kr / 118)
- 대검찰청 사이버수사과 (www.spo.go.kr / 1301)
- 경찰청 사이버안전국 (cyberbureau.police.go.kr / 182)

## 제11조 (방침의 변경)
이 방침은 시행일로부터 적용되며, 변경 시 공지사항을 통해 고지합니다. 변경 내용이 회원에게 불리한 경우 시행일 7일 전까지 고지합니다.
