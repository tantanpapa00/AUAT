Release Notes

v1.0.0 (2026-02-04) - Beta Release

Initial beta release

Features

  • Multi-exchange support: OKX, Binance, Bybit, Upbit, KIS
  • TradingView webhook integration (/tv endpoint)
  • Premium signals: Trend, Mean Reversion, Custom rules
  • Custom Rule Builder with AST-based validation
  • E-STOP emergency stop functionality
  • Timeline view for order tracking
  • Subscription/Entitlement system
  • Security: Sensitive data masking, security headers

PC Application

  • Windows installer (.exe)
  • System tray integration
  • Diagnostic report export
  • Auto-start and dashboard launch

Android Application

  • APK installation (sideload)
  • Dashboard monitoring (read-only)
  • E-STOP toggle
  • Event notifications (basic)

Known Issues

  • KIS: 장 마감 시간(15:30 KST) 이후 주문 실패
  • Upbit: IP 화이트리스트 필수 (미등록 시 인증 실패)
