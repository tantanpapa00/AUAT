Installation Guide

1. Windows PC 설치

  1. 다운로드 페이지에서 Windows 설치 파일 다운로드
  2. 다운로드한 BBooster-Setup.exe 실행
  3. 설치 마법사의 안내에 따라 설치 진행
  4. 설치 완료 후 바탕화면의 BBooster 아이콘 클릭
  5. 서버가 자동 시작되고 대시보드가 브라우저에서 열립니다

2. Android APK 설치

2-1. "알 수 없는 앱 설치" 허용

BBooster APK는 PlayStore가 아닌 직접 설치이므로, 먼저 허용 설정이 필요합니다.

Android 8.0 이상 (Oreo+)

  1. APK 다운로드 시 "이 출처 허용" 팝업이 뜨면 → 허용 선택
  2. 또는: 설정 → 앱 → 특별 액세스 → 알 수 없는 앱 설치
  3. Chrome 또는 파일 관리자에서 "허용" 활성화

Android 7.0 이하

  1. 설정 → 보안
  2. "알 수 없는 출처" 또는 "알 수 없는 앱 설치" 활성화

2-2. APK 설치

  1. 다운로드 페이지에서 BBooster-v0.1.0.apk 다운로드
  2. 다운로드 완료 알림을 탭하거나, 파일 관리자에서 APK 파일 선택
  3. "설치" 버튼 클릭
  4. 설치 완료 후 "열기" 클릭

2-3. 앱 초기 설정

  1. 앱 실행 후 설정(⚙️) 버튼 탭
  2. Server URL에 PC 서버 주소 입력 (예: http://192.168.1.100:8000)
  3. "Save Settings" 탭
  4. 메인 화면으로 돌아가면 서버 연결 상태 확인

서버 URL 확인 방법

PC 프로그램 실행 후 트레이 아이콘 → Dashboard 열기 시 표시되는 주소 사용

같은 Wi-Fi 네트워크에 연결되어 있어야 합니다.

주의사항

  • 앱은 관측/모니터링 전용입니다
  • API 키 등록은 PC에서만 가능합니다
  • E-STOP 제어만 허용됩니다 (수동 주문 불가)

3. 초기 설정

3-1. 계좌/API 키 등록 (PC)

  1. 거래소에서 API 키 발급 (출금 권한 없는 키 필수)
  2. PC 프로그램 → 계좌 → 거래소 선택
  3. API Key, Secret, Passphrase(OKX) 입력
  4. "연결 테스트" 버튼으로 확인
  5. 저장

3-2. TradingView 템플릿 생성 (PC)

  1. PC 프로그램 → 템플릿
  2. 거래소/심볼/방향 선택
  3. "템플릿 생성" 클릭
  4. 생성된 JSON 복사
  5. TradingView → Alert → Webhook URL에 서버 주소 입력
  6. Message에 복사한 JSON 붙여넣기

3-3. E-STOP 테스트

  1. PC 프로그램 → 설정 → E-STOP
  2. "E-STOP ON" 버튼 클릭
  3. 상태가 "정지됨"으로 변경 확인
  4. "E-STOP OFF"로 해제

4. 거래소별 API 키 발급

OKX

  1. OKX 로그인 → API 관리
  2. "API 생성" 클릭
  3. 권한: 읽기(Read) + 거래(Trade) 선택
  4. 출금(Withdraw) 절대 선택 금지
  5. IP 화이트리스트 설정 (권장)
  6. API Key, Secret Key, Passphrase 저장

Binance

  1. Binance 로그인 → API Management
  2. "Create API" 클릭
  3. 권한: Enable Reading + Enable Spot Trading
  4. Enable Withdrawals 절대 선택 금지
  5. IP 접근 제한 설정 (권장)

Upbit

  1. Upbit 로그인 → Open API 관리
  2. "Open API Key 발급" 클릭
  3. 자산조회 + 주문하기 권한 선택
  4. IP 주소 등록 필수

5. 문제 해결

자주 발생하는 문제는 FAQ를 참조하세요.

진단 리포트가 필요한 경우:

  1. PC 프로그램 → 트레이 아이콘 → 진단 내보내기
  2. 생성된 zip 파일을 지원팀에 전달
