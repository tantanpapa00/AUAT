FAQ (자주 묻는 질문)

설치/실행

Q: 설치 후 프로그램이 실행되지 않습니다.

A: 다음을 확인하세요:
1. Windows 10/11 64-bit인지 확인
2. 바이러스 백신에서 차단되지 않았는지 확인
3. 관리자 권한으로 실행 시도
4. 진단 리포트를 내보내어 지원팀에 문의

Q: 서버가 시작되지 않습니다.

A: 포트 8000이 다른 프로그램에서 사용 중일 수 있습니다. 작업 관리자에서 충돌하는 프로세스를 종료하거나, 설정에서 포트를 변경하세요.

Q: Android APK 설치가 안 됩니다.

A: 설정 → 보안 → "알 수 없는 앱 설치"를 허용해야 합니다. 설치 가이드를 참조하세요.

연결/API

Q: API 연결이 실패합니다.

A: 다음을 확인하세요:
1. API Key, Secret, Passphrase가 정확한지
2. 거래소 API 권한에 "읽기"와 "거래"가 포함되어 있는지
3. IP 화이트리스트 설정이 되어 있다면 현재 IP가 등록되어 있는지
4. 거래소 서버 상태 확인 (점검 중일 수 있음)

Q: Upbit 연결이 안 됩니다.

A: Upbit은 IP 화이트리스트가 필수입니다. Upbit API 관리에서 현재 IP를 등록해야 합니다.

Q: KIS 주문이 실패합니다.

A: KIS는 장 운영 시간(09:00~15:30 KST)에만 주문이 가능합니다. 시간 외에는 주문이 거부됩니다.

주문/거래

Q: 주문이 전송되지 않습니다.

A: 다음을 확인하세요:
1. E-STOP이 OFF 상태인지
2. DRY_RUN 모드가 아닌지
3. 잔고가 충분한지
4. 심볼이 올바른지 (예: BTC-USDT)

Q: E-STOP은 무엇인가요?

A: E-STOP(비상 정지)은 모든 신규 주문을 즉시 차단하는 기능입니다. 시장 급변 시 손실을 방지하거나, 잘못된 신호 발생 시 사용합니다. PC, 앱, 웹 모두에서 제어 가능합니다.

Q: TradingView 알림이 도착하지 않습니다.

A: 다음을 확인하세요:
1. TradingView Alert의 Webhook URL이 정확한지
2. 서버가 실행 중인지
3. 방화벽이 포트 8000을 허용하는지
4. JSON 형식이 올바른지 (템플릿 사용 권장)

Premium/Custom

Q: Premium 신호가 생성되지 않습니다.

A: 다음을 확인하세요:
1. Premium 구독이 활성화되어 있는지
2. 해당 전략 모드(trend/mr/custom)가 활성화되어 있는지
3. 쿨다운 시간(60초)이 지났는지
4. 일일 신호 제한(100개)에 도달하지 않았는지

Q: 왜 15분봉 이상을 권장하나요?

A: 1~5분봉은 슬리피지(체결 가격 차이)와 체결 지연으로 인해 예상과 다른 결과가 발생할 수 있습니다. 15분봉 이상에서 더 안정적인 성과를 기대할 수 있습니다.

보안

Q: API 키가 안전한가요?

A: API 키는 로컬 PC에만 암호화되어 저장됩니다. 서버로 전송되지 않습니다. 단, 반드시 "출금 권한 없는" API 키를 사용하세요.

Q: 왜 출금 권한 없는 키를 사용해야 하나요?

A: 만약의 보안 사고에도 자산 출금이 불가능하도록 하기 위함입니다. 거래 권한만으로도 자동매매에 충분합니다.

기타

Q: 선물/레버리지 거래가 가능한가요?

A: 아니요, BBooster는 현물(Spot) 거래만 지원합니다. 선물/레버리지 상품은 전면 미지원입니다.

Q: 환불이 가능한가요?

A: 투자 손실, 사용자 설정 오류, TradingView 신호 문제 등은 환불 대상이 아닙니다. 자세한 내용은 면책 조항을 참조하세요.
