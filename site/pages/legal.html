면책 조항 (Disclaimer)

최종 수정일: 2026-02-04

1. 투자 위험 고지

BBooster는 자동매매를 "대행"하는 것이 아니라, 사용자가 설정한 조건에 따라 주문을 "전송"하는 도구입니다. 모든 투자 결정과 그에 따른 손익에 대한 책임은 전적으로 사용자에게 있습니다.

2. 수익 보장 불가

BBooster의 어떤 기능도 미래 수익을 보장하지 않습니다. Premium 전략(추세/역추세/커스텀)은 과거 데이터를 기반으로 설계되었으며, 과거 성과가 미래 수익을 보장하지 않습니다.

3. 기술적 위험

다음과 같은 기술적 문제로 인해 예상과 다른 결과가 발생할 수 있습니다:

  • 네트워크 지연 또는 장애
  • 거래소 API 오류 또는 점검
  • 슬리피지 (신호 가격과 체결 가격 차이)
  • 시스템 오류

4. 환불 불가 사유

다음 사유로 인한 손실은 환불 대상이 아닙니다:

  • 시장 변동으로 인한 투자 손실
  • 사용자 설정 오류 (잘못된 심볼, 수량 등)
  • TradingView에서 설정한 Alert 조건
  • 사용자가 직접 만든 커스텀 규칙
  • 슬리피지로 인한 가격 차이
  • API 키 문제 (권한, 만료, IP 제한)
  • 거래소 측 장애

5. API 키 보안

반드시 "출금 권한 없는" API 키를 사용해야 합니다. 출금 권한이 포함된 API 키 사용으로 인한 손실에 대해 BBooster는 책임지지 않습니다.

이용 약관 (Terms of Service)

최종 수정일: 2026-02-04

1. 서비스 정의

BBooster는 TradingView 알림을 거래소에 전송하는 자동화 도구입니다. 투자 자문, 종목 추천, 자동 종목 선정 서비스가 아닙니다.

2. 이용 자격

  • 만 19세 이상의 성인
  • 해당 국가에서 암호화폐/주식 거래가 합법인 경우
  • 거래소 이용 약관을 준수하는 경우

3. 금지 행위

  • 서비스를 이용한 불법 행위
  • 시세 조종 등 시장 질서 교란 행위
  • 소프트웨어 역공학, 복제, 배포
  • 다른 사용자의 계정 무단 사용

4. 서비스 변경/중단

BBooster는 사전 공지 후 서비스를 변경하거나 중단할 수 있습니다. 긴급한 경우 사후 공지할 수 있습니다.

5. 지원 거래소

현재 지원: OKX, Binance, Bybit, Upbit, KIS (한국투자증권)

현물(Spot) 거래만 지원합니다. 선물/레버리지 상품은 미지원입니다.

개인정보 처리방침 (Privacy Policy)

최종 수정일: 2026-02-04

1. 수집하는 정보

  • 계정 정보: 이메일, 비밀번호 (암호화 저장)
  • 구독 정보: 플랜, 결제 내역
  • 사용 로그: API 호출 기록, 주문 기록 (마스킹 적용)

2. 수집하지 않는 정보

  • 거래소 API 키: 로컬 PC에만 저장, 서버 전송 안 함
  • 자산 정보: 잔고, 보유 종목 등
  • 거래 상세: 체결 가격, 수량 등 (로컬 로그에만 저장)

3. 정보 이용 목적

  • 서비스 제공 및 개선
  • 구독 관리 및 결제 처리
  • 고객 지원
  • 서비스 오류 분석

4. 정보 보유 기간

  • 계정 정보: 회원 탈퇴 시 즉시 삭제
  • 결제 정보: 관련 법령에 따른 보관 기간 (5년)
  • 사용 로그: 30일 후 자동 삭제

5. 제3자 제공

법적 요구가 있는 경우를 제외하고 개인정보를 제3자에게 제공하지 않습니다.

6. 보안

  • 모든 통신은 HTTPS 암호화
  • 비밀번호는 단방향 해시 저장
  • 민감 정보는 마스킹 처리

7. 사용자 권리

사용자는 언제든지 자신의 정보를 조회, 수정, 삭제 요청할 수 있습니다.
