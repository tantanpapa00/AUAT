투자위험고지

최종 수정일: 2026년 2월 4일

경고

암호화폐 및 주식 거래는 높은 위험을 수반합니다. 투자금 전액을 잃을 수 있습니다. 자동 매매 시스템은 이러한 위험을 줄이지 않으며, 오히려 시스템 오류로 인해 추가적인 위험이 발생할 수 있습니다. 투자 결정은 전적으로 이용자 본인의 책임입니다.

1. 시장 위험

  • 가격 변동성: 암호화폐 및 주식 시장은 극심한 가격 변동을 겪을 수 있으며, 단기간에 큰 손실이 발생할 수 있습니다.
  • 유동성 위험: 특정 자산의 거래량이 부족한 경우 원하는 가격에 매매가 어려울 수 있습니다.
  • 시장 조작: 암호화폐 시장은 전통 금융 시장에 비해 규제가 적어 시장 조작에 취약할 수 있습니다.
  • 규제 변화: 각국의 규제 정책 변화로 인해 자산 가치가 급변할 수 있습니다.

2. 자동 매매 시스템 위험

2-1. 기술적 위험

  • 시스템 오류: 소프트웨어 버그, 서버 장애, 네트워크 문제 등으로 인해 주문이 실행되지 않거나 의도치 않게 실행될 수 있습니다.
  • 지연: 네트워크 지연, API 응답 지연 등으로 인해 주문이 원하는 시점에 실행되지 않을 수 있습니다.
  • 거래소 장애: 거래소 API 장애, 점검, 과부하 등으로 인해 서비스가 정상적으로 작동하지 않을 수 있습니다.
  • 웹훅 실패: TradingView 웹훅 전송 실패, 네트워크 문제 등으로 신호가 전달되지 않을 수 있습니다.

2-2. 전략 위험

  • 과거 성과: 과거의 수익률이 미래의 수익을 보장하지 않습니다. 백테스트 결과와 실제 결과는 다를 수 있습니다.
  • 과최적화: 과거 데이터에 과도하게 최적화된 전략은 실제 시장에서 성과가 저조할 수 있습니다.
  • 시장 체제 변화: 시장 환경이 변화하면 기존에 잘 작동하던 전략도 손실을 낼 수 있습니다.

중요: 자동 매매 시스템이 "자동"으로 수익을 창출한다는 것은 잘못된 기대입니다. 모든 거래 전략은 손실을 볼 수 있으며, 시스템은 단지 미리 정의된 규칙을 실행할 뿐입니다.

3. API 키 보안 위험

  • 유출 위험: API 키가 유출되면 제3자가 이용자의 계정에서 거래를 실행할 수 있습니다.
  • 권한 설정: API 키 생성 시 반드시 출금 권한을 제외하고, 거래 권한만 부여하시기 바랍니다.
  • IP 제한: 가능한 경우 API 키에 IP 화이트리스트를 설정하시기 바랍니다.

4. 레버리지 위험

  • 증폭된 손실: 레버리지 거래는 수익과 손실을 모두 증폭시킵니다. 원금 이상의 손실이 발생할 수 있습니다.
  • 청산: 레버리지 거래에서 급격한 가격 변동 시 포지션이 강제 청산될 수 있습니다.
  • 펀딩 비용: 선물 거래 시 펀딩 수수료가 발생하며, 이는 수익을 감소시킬 수 있습니다.

5. 면책 조항

  • BBooster는 투자 자문 서비스가 아닙니다. 본 서비스는 이용자가 설정한 전략을 자동으로 실행하는 도구일 뿐입니다.
  • 이용자의 투자 결정, 전략 선택, 거래 결과에 대해 BBooster는 어떠한 책임도 지지 않습니다.
  • 시스템 오류, 거래소 장애, 네트워크 문제 등으로 인한 손실에 대해 BBooster는 책임지지 않습니다.
  • 본 서비스 이용으로 인해 발생하는 모든 손실은 전적으로 이용자 본인의 책임입니다.

6. 권장 사항

  • 소액 테스트: 실제 자금을 투입하기 전에 소액으로 충분히 테스트하시기 바랍니다.
  • 손실 감당 범위: 잃어도 생활에 지장이 없는 금액만 투자하시기 바랍니다.
  • E-STOP 활용: 이상 징후 발견 시 즉시 E-STOP으로 모든 거래를 중단하시기 바랍니다.
  • 모니터링: 자동 매매 시스템이라도 정기적으로 상태를 확인하시기 바랍니다.
  • 분산 투자: 한 전략, 한 자산에 집중하지 말고 분산 투자하시기 바랍니다.

최종 경고

본 서비스를 이용한다는 것은 위에 명시된 모든 위험을 충분히 이해하고 수용한다는 것을 의미합니다. 투자에는 원금 손실의 위험이 있으며, 자동 매매 시스템 사용이 이 위험을 제거하지 않습니다. 모든 투자 결정은 신중하게 내리시기 바랍니다.
