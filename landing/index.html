Why BBooster?

강력하고 유연한 자동 매매 솔루션

📡

TradingView Webhook

TradingView 알림과 완벽하게 연동. 전략 시그널을 실시간으로 수신하고 즉시 주문 실행.

🔌

멀티 거래소 지원

OKX, KIS, Binance, Bybit, Upbit 등 주요 거래소 API 연동. 하나의 전략으로 다양한 거래소에서 실행.

🛑

E-STOP 긴급 정지

이상 상황 발생 시 원클릭으로 모든 주문 즉시 차단. 웹, PC앱, 모바일 어디서든 제어.

📊

실시간 모니터링

타임라인, 주문 내역, 커넥터 상태를 한눈에. 모든 거래 활동을 투명하게 추적.

🧠

전략 관리

PineScript 파라미터 자동 파싱. 설정 해시 기반 버전 관리로 전략 변경 추적.

🐳

Docker 배포

docker-compose 한 줄로 완벽한 환경 구성. PostgreSQL + App + ngrok 통합 제공.

How it works

간단한 4단계로 자동 매매 시작

1

거래소 계정 등록

API 키를 등록하고 거래소 연결을 확인합니다.

2

전략 설정

TradingView 전략 파라미터를 동기화하고 설정을 저장합니다.

3

자산 연결

계정과 전략을 심볼에 연결하여 자동 매매 자산을 구성합니다.

4

웹훅 설정

TradingView에 웹훅 URL을 등록하면 자동 매매가 시작됩니다.
