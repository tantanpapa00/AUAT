자주 묻는 질문

BBooster에 대해 궁금한 점을 확인하세요

BBooster는 무엇인가요?

BBooster는 TradingView 전략 신호를 받아 거래소에 자동으로 주문을 실행하는 자동매매 허브입니다. 직접 전략을 만들거나, 내장된 Premium 전략을 사용할 수 있습니다.

어떤 거래소를 지원하나요?

현재 OKX, 한국투자증권(KIS), Binance, Bybit, Upbit 5개 거래소의 현물 거래를 지원합니다. 선물(Futures) 거래는 지원하지 않습니다.

투자 원금 손실 가능성이 있나요?

예, 모든 투자에는 원금 손실 위험이 있습니다. BBooster는 자동매매 도구일 뿐, 투자 수익을 보장하지 않습니다. 투자 결정은 본인의 판단과 책임 하에 이루어져야 합니다.

API 키는 안전한가요?

API 키는 암호화되어 저장되며, 출금 권한이 없는 키만 사용하도록 권장합니다. 또한 E-STOP 기능으로 이상 상황 시 즉시 모든 주문을 차단할 수 있습니다.

수수료가 있나요?

BBooster 자체 수수료와 거래소 거래 수수료는 별개입니다. BBooster 이용료는 플랜별로 다르며, 거래소 수수료는 각 거래소 정책에 따릅니다.
