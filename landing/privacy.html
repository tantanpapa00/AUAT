개인정보처리방침

시행일: 2026년 1월 1일 | 최종 수정일: 2026년 2월 5일

큐브시스템(이하 "회사")은 정보통신망 이용촉진 및 정보보호 등에 관한 법률, 개인정보보호법 등 관련 법령에 따라 이용자의 개인정보를 보호하고 이와 관련한 고충을 신속하게 처리하기 위하여 다음과 같이 개인정보처리방침을 수립합니다.

제1조 (수집하는 개인정보)

회사는 서비스 제공을 위해 최소한의 개인정보만을 수집합니다:

1.1 필수 수집 항목

항목 수집 목적
이메일 주소 계정 생성, 로그인, 중요 공지 발송
거래소 API 키 거래소 연동 및 주문 실행

1.2 자동 수집 항목

항목 수집 목적
접속 로그 (IP, 접속 시간) 보안 및 부정 이용 방지
서비스 이용 기록 서비스 개선 및 통계 분석

API 키 관련 안내: 회사는 출금(Withdraw) 권한이 없는 API 키만 사용하도록 강력히 권장합니다. 출금 권한이 있는 API 키는 등록을 거부할 수 있습니다.

제2조 (개인정보의 처리 목적)

회사는 수집한 개인정보를 다음의 목적으로만 처리합니다:

  1. 서비스 제공: 회원 가입, 로그인, 서비스 이용
  2. 주문 실행: 거래소 API를 통한 매매 주문 전달
  3. 고객 지원: 문의 응대, 불만 처리, 공지사항 전달
  4. 서비스 개선: 이용 통계 분석, 신규 기능 개발
  5. 보안: 부정 이용 방지, 보안 위협 대응

제3조 (개인정보의 보유 및 파기)

3.1 보유 기간

항목 보유 기간
계정 정보 (이메일) 회원 탈퇴 후 30일
거래소 API 키 회원 탈퇴 즉시 삭제
접속 로그 3개월
거래 기록 회원 탈퇴 후 30일

3.2 파기 절차 및 방법

  • 전자적 파일 형태: 복구 불가능한 방법으로 영구 삭제
  • API 키: 암호화 키와 함께 즉시 영구 삭제

제4조 (개인정보의 제3자 제공)

회사는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 단, 다음의 경우는 예외로 합니다:

  1. 이용자가 사전에 동의한 경우
  2. 법령에 의하여 제공이 요구되는 경우
  3. 서비스 제공을 위해 필요한 범위 내에서 거래소에 주문을 전달하는 경우 (API 키 사용)

명확히 하면: 회사는 이용자의 API 키를 이용하여 거래소에 주문만 전달합니다. 개인정보 자체를 거래소에 제공하지 않으며, API 키를 제3자에게 공유하지 않습니다.

제5조 (API 키 보안)

회사는 이용자의 API 키를 다음과 같이 안전하게 보호합니다:

  • 암호화 저장: AES-256 암호화 알고리즘으로 암호화하여 저장
  • 전송 보안: TLS 1.2 이상의 암호화 통신으로 전송
  • 접근 제한: 주문 실행 시에만 복호화하여 사용
  • 로그 제외: API 키는 로그에 기록되지 않음
  • 권한 제한: 출금 권한이 없는 API 키만 권장

제6조 (이용자의 권리)

이용자는 언제든지 다음의 권리를 행사할 수 있습니다:

  1. 개인정보 열람 요구: 본인의 개인정보 처리 현황 확인
  2. 개인정보 정정 요구: 부정확한 정보의 정정 요청
  3. 개인정보 삭제 요구: 회원 탈퇴를 통한 개인정보 삭제
  4. 처리 정지 요구: 개인정보 처리의 정지 요청

권리 행사는 서비스 내 설정 메뉴 또는 고객센터를 통해 가능합니다.

제7조 (쿠키의 사용)

회사는 서비스 제공을 위해 쿠키를 사용할 수 있습니다:

  • 필수 쿠키: 로그인 유지, 세션 관리
  • 분석 쿠키: 서비스 이용 통계 (익명화)

이용자는 브라우저 설정을 통해 쿠키 저장을 거부할 수 있습니다.

제8조 (개인정보 보호책임자)

회사는 개인정보 처리에 관한 업무를 총괄하는 개인정보 보호책임자를 다음과 같이 지정합니다:

구분 내용
직책 개인정보 보호책임자
이메일 privacy@qube.com

제9조 (개인정보처리방침의 변경)

본 개인정보처리방침은 관련 법령 또는 회사 정책의 변경에 따라 변경될 수 있습니다. 변경 시 서비스 내 공지사항을 통해 최소 7일 전에 안내합니다.

문의: 개인정보 관련 문의는 privacy@qube.com 으로 연락해 주시기 바랍니다.
