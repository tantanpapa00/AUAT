● 확인 중...
마지막 변경: --
사유: --

긴급 정지가 활성화되면 모든 TradingView 웹훅 주문이 차단됩니다.

시스템 상태 (읽기 전용)

이 설정들은 서버 환경 변수로 제어됩니다

DRY_RUN -- 모의 주문 (실제 거래 없음)
ORDER_SUBMIT -- 주문 제출 활성화
ORDER_POLL -- 주문 상태 폴링 활성화
서버 -- 백엔드 서버 연결

이 설정을 변경하려면 서버의 .env 파일을 수정하고 재시작하세요.
